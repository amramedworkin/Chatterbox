# Comprehensive Cursor Rules Extraction Instructions

## Overview
This document provides a structured approach for extracting comprehensive cursor rules from a mature, well-functioning project. These instructions guide the analysis of existing project patterns and practices to create detailed rule sets that codify what was done right and ensure consistent development practices, automation, and quality standards across future development.

## Purpose
The goal is to analyze an existing mature project, identify the successful patterns and practices that made it work well, and extract these into a series of specialized cursor rule files. These rules will guide AI assistance in understanding and following the proven project-specific patterns, conventions, and requirements that have already demonstrated success. The rules ensure that all future code generation, suggestions, and assistance align with the established project standards that have proven effective.
